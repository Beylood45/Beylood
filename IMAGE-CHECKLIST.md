## How to upload


1. Rename each photo to match the **Filename** column above exactly.
2. Drop the JPG into `assets/images/<folder>/`.
3. Upload that folder to Hostinger `public_html/assets/images/`.
4. Refresh the site — covers appear automatically.


## Optional: WebP support


If you want WebP for faster loading, also drop a `<slug>.webp` next to
each `<slug>.jpg`. The site will use it automatically if present.
